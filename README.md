# NARVA-JÕESUU WINTER FEST 2027

Сайт фестиваля: https://k0gar1n.github.io/narva-joesuu-winter-fest/

23–24 января 2027 · Narva-Jõesuu, Estonia · MTÜ Noorteaeg.

Русская, эстонская и английская версии. Спорт и активности, Winter Cup, программа, поездка, информация для посетителей, торговцев, волонтёров и партнёров.

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. После изменения этих файлов и отправки на GitHub сайт обновится автоматически.

`docs/config.js` содержит пять заменяемых ссылок: три регистрации Fienta и две формы для торговцев и волонтёров. Пока прямые ссылки не добавлены, используются переходы в Fienta и письмо организатору. Условия Cup и программа пока предварительные.

Для повторного экспорта из основной рабочей версии сайта: `node tools/export-pages.mjs ../website/dist`. Экспорт обновляет `docs`, добавляя пути GitHub Pages; затем изменения нужно отправить в `main`.

## Vercel

Импортировать этот репозиторий в Vercel, оставив Root Directory в корне репозитория. Параметры автоматически читаются из `vercel.json`: Other, сборка `node tools/build-vercel.mjs`, результат `dist`. GitHub Pages продолжает использовать папку `docs`.

Основной адрес в метаданных и sitemap: `https://www.winterfest.ee`. При смене домена переопределить его переменной `SITE_URL` и повторить публикацию. Домен добавляется отдельно в Settings → Domains, DNS — у регистратора.

Сборка Vercel снимает префикс GitHub Pages с внутренних адресов, изображений и переключения языков, сохраняя исходную версию в `docs`.
