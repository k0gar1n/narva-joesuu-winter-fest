# Website editorial and design rules

User preferences confirmed 2026-10-01. Apply to future page work as well as current edits.

- Use literal activity names as headings. No invented slogans, motivational copy, vague overlines, or numbered decorative headings.
- Keep text brief and factual. Avoid repetitive facts, unnecessary em dashes, and prose explaining what the layout already makes clear.
- Put the essential details and primary action where visitors see them immediately. Do not bury registration at the bottom of a long page.
- Use the existing festival typography, colors and visual language. Do not give every section a different style or font.
- Prefer one strong page title, an effective photograph and a compact useful layout over a sequence of generic landing-page sections.
- Desktop and mobile should have deliberately adapted layouts. Activity hero photos may fill the desktop opening screen; follow the homepage's separate title/photo treatment on mobile where appropriate.
- Avoid redundant "All activities", "View times", location captions and repeated free/date labels unless they serve a requested purpose.
- Use user-supplied photos when provided. Do not add unsolicited source links or credits to those photos.
- When the user requests a final-looking page before supplying a registration URL, show the intended registration control as an accessible disabled button. Do not invent a URL or add "link coming later" copy.
- Keep changes scoped, support RU/ET/EN, and save a recoverable Git checkpoint before design changes.
