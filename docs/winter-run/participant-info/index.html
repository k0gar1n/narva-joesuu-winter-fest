Номер и регистрация+

Выдача номеров 23 января с 11:00 до 12:00 у порта, Suur-Lootsi 4. Подготовьте подтверждение регистрации Fienta. При покупке нескольких билетов данные заполняются отдельно для каждого участника. Регистрация на месте проходит в часы выдачи номеров.

Дистанция и результат+

3,5 км — один круг, 7 км — два круга. На обеих дистанциях предусмотрен электронный хронометраж. Детский забег 300 м проходит без определения мест. Ссылку на результаты опубликуем здесь после забега.

Что взять с собой+

Одежду для зимнего бега, перчатки, шапку и обувь с хорошим сцеплением. После финиша пригодится сухая тёплая одежда. Для бани возьмите свои полотенце, купальные принадлежности и тапочки.

Вещи, переодевание и душ+

На территории фестиваля предусмотрены место для вещей, переодевалка, душ и туалеты. Расположение покажем в информации перед стартом.

Бани после забега+

С 13:00 до 15:00 участник может один раз бесплатно посетить банную зону, предъявив стартовый номер. Сохраните номер после финиша. Принадлежности нужно принести с собой.

Медали и награждение+

Медаль получает каждый финишировавший. На дистанциях 3,5 и 7 км отдельно награждаем трёх лучших мужчин и трёх лучших женщин. В детском забеге места не определяются. Награждение планируется около 13:30, место уточним.

Погода и изменения+

Следите за этой страницей перед поездкой. При небезопасной погоде организатор может перенести или отменить забег. В случае отмены стартовый взнос возвращается полностью. Об изменениях сообщим зарегистрированным участникам.
